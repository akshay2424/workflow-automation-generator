SOP: Customer Refund Processing
Department: Finance Operations
Owner: finance-ops@company.com

1. Customer submits a refund request through the support portal, including
   order ID and reason for refund.
2. Support agent reviews the request and verifies the order exists in the
   order management system.
3. If the order cannot be found, the agent rejects the request and notifies
   the customer that the order ID is invalid.
4. If the order is found, the agent checks the refund amount.
   - If the refund amount is under $500, the agent has authority to approve
     it directly.
   - If the refund amount is $500 or more, the request must be escalated to
     a Finance Manager for approval.
5. If the Finance Manager rejects the escalated request, the customer is
   notified that the refund was denied, with a reason.
6. If the Finance Manager approves the escalated request, or if the agent
   approved it directly, the request moves to Accounts Payable.
7. Accounts Payable processes the refund via the original payment method and
   issues a confirmation number.
8. The system sends a confirmation email to the customer with the refund
   confirmation number, and the ticket is closed.
